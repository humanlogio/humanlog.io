# Installation

To install `humanlog`, run this in your terminal:

```bash
curl -L "https://humanlog.io/install.sh" | sh
```

This will install `humanlog` as a background service and show a systray entry. You can then run queries with:

```bash
humanlog query 'summarize count() by msg'
```

We hope you enjoy the query engine and provide any feedback in [our community channels](/support).

## More Details

More details on installing the CLI can be found in the [CLI section of the documentation](/docs/features/cli).

## Platforms

We support:

- _macOS_: full support
- _linux_: must manually run `humanlog service run` to run the localhost engine (support for systemd service coming soon)

While we currently only support macOS and linux for the query engine, this is simply a matter of focus and not a hard long term restriction. We plan to support other platforms later, based on customer demand. If you would like to contribute support for your platform, please head over to the CLI's repo and look at the [service handler](https://github.com/humanlogio/humanlog/blob/master/cmd/humanlog/service_other.go) and the [systray handler](https://github.com/humanlogio/humanlog/blob/master/cmd/humanlog/systray_other.go).
