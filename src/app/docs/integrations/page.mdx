# Integrations

Humanlog integrates with the following technologies

- [OpenTelemetry](/docs/integrations/opentelemetry) where we currently support tracing data. Support for other signals is planned.
- [Structured logging](/docs/integrations/structured-logging) in JSON (`ndjson`) or `logfmt` format.
- [Containers](/docs/integrations/containers) where you can learn how to use humanlog with container runtimes.
