# Introduction

What's the difference between logs and traces?

## Conceptual Idea

When it comes to observability data, we often talk about three pillars:

- [**Logging**](/docs/concepts/logging): a set of list of events through systems.
- [**Tracing**](/docs/concepts/tracing): a set of directed graph of events through systems.
- **Metrics**: an aggregated value representing events that occurred at a given location in a system.
