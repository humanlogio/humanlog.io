# License

Humanlog is free (as in beer) for personal use. If you use Humanlog for work (business, commercial use), [you need a license](/pricing).

The `humanlog` CLI is partially free (as in freedom) for the core parsing features, which are MIT licensed. However, the localhost engine is proprietary. Binaries distributed by our official installation channel include the proprietary components. Usage of proprietary components require signing in.

For more details on the license, read [our terms of service](/legal/siteterms).

        ## FOSS purists

        The `humanlog` CLI is at its core FOSS software. However the Humanlog platform is a commercial project, so some components are proprietary. We may revisit this later, but for now this is how we build.

        If you are concerned about using only FOSS components, you may:
        - simply never sign up or log in, and no proprietary usage will be involved
        - build humanlog from source from the [repo](/link/github), which will not include any proprietary components
