# Themes

Themes allow you to customize the appearance of your data in the UI and CLI. You can change the default themes used by both the UI and the CLI [in your settings](/settings/localhost).

<img src="/images/docs/features/themes/localhost-settings.png" width="80%" />

Clicking on the color of a theme will open a color picker where you can select a new color for that component of the UI.

<img src="/images/docs/features/themes/theme-edit-ui.png" width="80%" />

When you save your settings, your localhost config file gets updated.

<img src="/images/docs/features/themes/theme-save-ui.png" width="80%" />

The CLI will now also be using the theme you saved.

<img src="/images/docs/features/themes/theme-view-cli.gif" width="80%" />

And the UI will update to reflect the changes in your query results.

<img src="/images/docs/features/themes/theme-view-ui.png" width="80%" />


<Note>
Not all settings available in the configuration are exposed in the UI, but we plan to expose more in the future.
</Note>
