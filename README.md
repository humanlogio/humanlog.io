# humanlog.io

The web frontend for [humanlog](https://github.com/humanlogio/humanlog) — logs and traces for humans to read.

This is the source code for [humanlog.io](https://humanlog.io), including the landing page, docs, blog, and the app itself (log streaming, querying, traces, dashboards, monitors).

Built with Next.js, React, and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```
